# 控制观察器开销与当前三批目标收口

本批只修正仓库评测工具的计量问题，没有修改 SDK、执行权威、授权、身份、效果或实际停止检查，没有新增模型请求。此前真实质量、原始时延和失败记录保持原样。

## 同包诊断与修复

沿用唯一推荐本地 SDK `0.1.0a8+maintenance.54f45574ad74b3af`，wheel SHA256 `3ca80c594b9d5e18946f4c016c41655754baee6284c8b96d05bc1107b9f64463`；451 产品文件和安装字节不变。环境为 macOS 15.6.1 ARM64／Python 3.12.7，无 CPU／内存硬限制，完整依赖沿用[真实任务批次](2026-10-29-default-task-quality.md)。原 Alpha 和前批私有包不重建。

旧 `Measurements` 在每个 Python 调用上用代码对象查字典。两个反例先失败：代码对象散列会遍历常量并调用无关对象的 `__hash__`；相等但不同的克隆代码会被误计为原 Engine 调用。原性能证据还承担全帧回调成本，不能直接归因于运行内核。

先在新进程进行 legacy／disabled／identity-only／local-event 四组各三次诊断。原 Plan `wire-a`、原离线 Provider、成员与父级完成 gate、一次重复及调用期限均固定，未改任务或物理工作。四组中位墙钟分别为 7.109／1.794／4.868／1.774 秒，支持将代码散列与全帧回调分别定位为观察器开销来源。

修复仅在 `tools/evaluate_default_chains.py`：

- 持有六个原同步方法的真实代码对象，以整数 identity 查询，避免散列、相等比较及 identity 回收；不读取帧参数、局部变量或模型正文，不替换 Engine 方法。
- Python 3.12+ 使用 `sys.monitoring` 的局部 `PY_START`，只启用 submit／approve／cancel／reconcile／status／diagnostics，计数仍限当前所有者线程，包含内部调用。没有打开全局事件。
- 已有 profiler、monitor owner、遗留 callback 或局部事件会拒绝启动，并保留外部注册。退出按顺序清除自己的局部事件、恢复 callback、释放工具槽位；清理失败保留所有权，拒绝重入并可重试原清理。
- 没有 monitoring 时使用 identity 查询的 `sys.setprofile` 回退。该路径仍有全帧成本；本轮在 Python 3.12 强制回退验证正确性，未授予真实 Python 3.11／3.13 平台资格。

CPython 的 `free_tool_id` 不会自动清除事件或 callback，显式清理依据[官方文档](https://docs.python.org/3.12/library/sys.monitoring.html)。这是验收工具的资源责任，没有引入框架调度或通用 profiler 组件。

## 首段和完整关闭边界

在相同精确安装上，以原 Agent／StreamedModelProvider／stream_updates 跑一次独立离线文本夹具：就绪 0.0535 秒、供应方夹具首段 0.0993 秒、框架消费首段 0.1900 秒、完整结果并退出 owned Agent 0.1967 秒。夹具有两次显式 0.02 秒暂停，只有一个模型 Action／一次 Provider 派发，预算 spent1／held0，观察到展示 delta 与权威 model_end，原迭代器清理债务为0。

它只证明端到端计时边界、单次派发与实际关闭，没有真实供应商质量或延迟含义。此前真实 Provider 单独流探针仍为首段0.506秒／完整0.587秒，不是 Agent 整链。本轮四条质量配置仍使用 complete，首段为 null；三种记录分开，不拼成不存在的真实流式业务性能。

## 回归、安装与失败保留

新增观察器测试12项，包含真实代码常量／克隆代码反例、真实原 Engine 操作、异常退出、注册失败、外部注册保护、跨线程计数和拒绝重入。新反例先失败后修复；本轮还保留首次 callback 与计时属性同名引起的两失败一错误，修复工具命名后通过，没有改 SDK 适配测试。

最终13个相关模块源码 **319 passed（69.99秒）**／目录外精确安装 **319 passed（70.06秒）**，`-W error`、零失败／跳过，测试 ID／字节一致，无 src 注入。修复后的完整离线四链路为24／24／15／15，RAG仍用原真实神经模型，生成由 fixture 完成，质量全部 null／不验收模型质量。

独立只读审查无重要未关闭项。局部事件禁用、callback 恢复、槽位释放三个清理失败，分别做了实际故障注入：所有权保留、重入拒绝、原对象重试后清理完成。它们目前是独立诊断证据，尚未成为三个长期自动 pytest 回归，作为低优先级测试覆盖待办记录，不是已发现的产品缺陷。

完整诊断／失败／注册清理证据位于 `dist/observer-cost-20261029/`，公开[机器摘要](../../evals/results/relf-observer-cost-20261029.json)不含提示、正文或凭据。原78条真实质量、204份数据库、旧质量公开摘要、451产品和9份保护制品逐项复核不变。静态、安装字节、同测试ID、原始计量与文档链接按最终冻结检查保存；未扩为全量 SDK 或平台验收。
