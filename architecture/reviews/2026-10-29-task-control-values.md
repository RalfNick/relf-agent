# TaskControlBridge 返回值校验维护

日期：2026-10-29。基线 `ac86036`。只修复已有同步／原生异步控制的返回契约，不新增功能、依赖、Schema、配置项或执行权威。原 a8 制品与所有历史失败保留。

## 已复现问题与修复

- **P2：DTO 内嵌非法数据泄漏原始异常。** 回执、状态与输入诊断使用 `canonical(asdict(value))`；`asdict` 先深拷贝，协程／线程锁触发原始 TypeError，循环数据触发 RecursionError，绕过统一 ValidationError。改为 JSON 遍历时投影 dataclass 字段，在复制前校验有限值及循环，再返回原 DTO 的独立副本。保留原有嵌套 DTO 支持和原字段值，不改变 wire 格式。
- **P2：状态字段未检查类型。** `apply_state`／`state` 误传列表或字典时，集合成员检查直接 TypeError。增加字符串形状检查，允许的状态集合保持；控制拒绝继续返回原拒绝回执。

桥接仍借用原 Engine，不 drive、关闭或转移执行；Scope／方法固定及调用前后校验保持。返回校验失败不能证明原命令未受理；修正适配器后以原身份和相同请求重试。无效 DTO 内的原生对象由生产方处置，桥接不进入协程或上下文管理器。
