# 0.1.0a8：扩展失败清理与关闭重试修复候选

日期：2026-10-26。发行名`relf-agent`、Python导入`relf_agent`、CLI`relf`／`relf-*`。本候选以`ac920069e206f39d75ef0ab334f41b0619ca5a27`为维护基线，纳入`7e9fac1`与`ac92006`，不新增功能、依赖、Schema或执行权威。相对基线产品只改版本与生成应用的安装提示。

## 已纳入修复

- 自定义CLI工厂返回Engine后，方法属性读取失败返回结构化配置错误；校验中断完成同步清理后传播原异常，关闭失败保留原资源和可重试句柄。
- RuntimeBuilder／ProfiledEngine先接管真实候选，再检查关闭接口；控制中断和close属性读取失败不会丢失清理责任，不提前释放Coordinator或关闭附属资源。
- 被拒绝Builder实例的cleanup句柄阻断业务访问，允许排空／关闭重试。正常已接受实例因忙碌拒绝同步关闭时，仍能取消原Run。

原始复现、失败和维护源码验证见[CLI清理](../../architecture/reviews/2026-10-25-cli-factory-cleanup.md)与[关闭所有权](../../architecture/reviews/2026-10-25-runtime-failure-ownership.md)。这些旧成绩只属于各原输入，不能代签a8。
